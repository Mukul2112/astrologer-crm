# AI Usage Declaration

This project was built with the assistance of several AI tools, including **Antigravity**, **ChatGPT**, **Gemini**, and **Stitch**. These tools were used as collaborative assistants to accelerate development while maintaining human oversight of the project.

## How AI Was Used
1. **Syntax & Code Structure**: AI models (ChatGPT, Gemini) were utilized to help structure boilerplate code, identify syntax errors, and suggest clean, modern ways to write React functions.
2. **UI Prototyping & Styling**: Tools like Stitch and Antigravity were referenced to help draft the React components and apply Tailwind CSS utility classes, ensuring a beautiful and responsive user interface.
3. **Dummy Data Generation**: To populate the UI for the demonstration, AI was utilized to generate a large volume of realistic mock data for clients and appointments, saving manual typing time.
4. **API & Database Assistance**: AI was used to help format standard fetch requests and debug database connection strings during the Supabase migration phase.

## Human Oversight & Verification
* The core architecture, database schema, and component relationships were guided by the project requirements.
* All generated code was thoroughly reviewed to ensure it met the project goals and functioned correctly without errors.
* Business logic, data flow, and integration testing were actively monitored and adjusted to ensure the final product is clean, scalable, and fully executable.
