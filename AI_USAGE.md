# AI Usage Declaration

This project was built with the assistance of an AI Coding Assistant (Antigravity/Gemini).

## How AI Was Used
1.  **Project Initialization & Boilerplate**: The AI assisted in setting up the Next.js project and configuring Tailwind CSS.
2.  **UI Design & Styling**: The AI generated the global CSS theme, including the glassmorphism effects, color palettes, and the overall premium astrological aesthetic.
3.  **Component Generation**: AI was used to draft the React components (Dashboard, Sidebar, Clients Table, Client Details, and Appointments views) based on the project requirements.
4.  **Mock Data Creation**: The AI generated realistic mock data (`src/lib/data.ts`) to populate the UI for the demonstration.

## Human Oversight
*   The overall architecture and feature decisions were guided and approved by me.
*   All generated code was reviewed to ensure it met the assignment requirements (no broken links, smooth UI flow).
*   I ensured the codebase remains clean, well-organized, and easily executable by evaluators.
