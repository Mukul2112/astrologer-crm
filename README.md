# Astrologer CRM

A premium, visually stunning CRM dashboard tailored for professional Astrologers, built with **Next.js** and **Tailwind CSS**.

## Features

- **Dashboard**: High-level overview of active clients, upcoming sessions, and revenue.
- **Client Directory**: Manage your clients, filter by Zodiac sign, and view basic contact details.
- **Client Profiles**: Deep dive into individual client details, including their Date/Time/Place of birth, and log consultation notes.
- **Appointments Manager**: Keep track of scheduled readings (e.g., Birth Chart Reading, Tarot, Career Consultation).
- **Premium UI**: Designed with a clean, light, human-centric aesthetic featuring soft drop shadows and an intuitive, modern layout.

## Quick Start

This project uses mock data, so no database configuration is required. Simply install the dependencies and run it!

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd astrologer-crm
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.
